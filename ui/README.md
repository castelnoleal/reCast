# reCast Studio

A lightweight browser UI for local reCast projects.

Open `ui/index.html` directly for the editor shell. It can preview HTML compositions, open local HTML files, validate composition settings, and provide the controls used by the reCast CLI workflow.

For actual MP4 generation, run `recast render` in the project directory. The browser UI intentionally stays framework-free and local-first so it can be used without a hosted service.
